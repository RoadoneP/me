## Project Description

<br />
**Project Title:** Research on Logistics Label Recognition and Document Understanding  
<br />
**Duration:** Jun. 2024 – Dec. 2024  
<br />
**Funding:** Supported by Hyundai Glovis  
<br />
**Role:** Project co-leader (Document Understanding)   
<br />
This project focused on developing technologies for **logistics label recognition and document understanding**.  
The research included tasks such as **logistics label detection (YOLO-based), document unwarping (UVDoc), image denoising (Restormer), key-value labeling, and OCR-free document understanding (Donut)**.  
By integrating these methods, the system achieved robust performance in extracting structured information from logistics labels under diverse environmental conditions.  
<br />
본 프로젝트는 **물류 라벨 인식 및 문서 내 정보 추출 자동화 기술 개발**을 목표로 하였습니다.  
연구는 **YOLO 기반 물류 라벨 검출, UVDoc을 활용한 문서 정렬, Restormer를 통한 노이즈 제거, Key-Value 레이블링, OCR-free Document Understanding (Donut)** 등을 포함하였습니다.  
이러한 기술들을 통합하여 다양한 환경에서 물류 라벨 정보를 안정적으로 추출할 수 있는 시스템을 구축하였습니다.
