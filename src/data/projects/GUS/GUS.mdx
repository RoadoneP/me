## Project Description

**Project Title:** GUS HT Document Recognition AI  
<br />
**Duration:** Mar. 2025 ~ Dec. 2025  
<br />
**Role:** Project leader  
<br />
**Scope:** Billing Invoice, Inbound POD, and Outbound POD document automation

This project focused on building a document AI pipeline for logistics operations. The system automated key information extraction and verification across multiple document types with different layouts and noisy handwritten inputs.

At a high level, the pipeline combined document preprocessing, visual-language understanding, and detection models to support practical document automation for real workflows.

## Overview

- Automated recognition for **Billing Invoice**, **Inbound POD**, and **Outbound POD**
- Combined preprocessing, document understanding, and detection modules in one pipeline
- Designed for practical logistics document processing rather than a single benchmark task

## Results Summary

- **Document Understanding:** **96.0%**
- **Stamp Detection:** **98.0%**
