## Project Description

<br />
**Project Title:** Squid Game: Red Light, Green Light Implementation.
<br />
This project implements the "Red Light, Green Light" game from Netflix's Squid Game using a Jetson Nano for real-time object detection and 3D printing for creating a functional Young-hee doll. The laser targeting system and motion detection algorithms enable precise tracking and control. The project showcases an innovative combination of AI and robotics for recreating the iconic game
